# 12 — VST3 (outline)

**This is an outline on purpose.** Write the full step after step 07 has
landed, using what the CLAP adapter showed about the neutral types.

## Why this should be cheap

Steps 02–11 leave everything above `mooloop-plugin-host` independent of the
plugin format. VST3 is one more module in that crate, `vst3`, implementing
`HostedInstance`, `HostedGui` and `AudioNode`, plus search paths for the
scanner.

## What is different, and where it lands

- **Bindings.** The `vst3` crate (0.3 on 2026-09-16) provides them.
  Steinberg moved the VST3 SDK to MIT in 2025, so the old GPL/proprietary
  licence question no longer applies. Check this against the SDK
  repository when writing the step.
- **Two components.** A VST3 plugin is a processor plus an edit controller,
  sometimes in one object and sometimes not. `PluginState` has chunks for
  this reason: `component` and `controller`.
- **Normalized parameters.** VST3 sends 0..1 values to the processor and
  converts them to and from plain values in the controller. The adapter
  converts at its boundary, so `ParamValue` keeps carrying plain values.
- **Sample-accurate parameter queues.** Each block, turn `ParamValue`
  events into `IParameterChanges` points.
- **Buses.** Negotiate one stereo main in and one stereo main out with
  `setBusArrangements`, the way step 06 negotiates CLAP ports. Instruments
  have event bus 0 in.
- **Notes.** `NoteOnEvent` / `NoteOffEvent` with `noteId`. The id table from
  step 10 is reused.
- **GUI.** `IPlugView` with `kPlatformTypeX11EmbedWindowID` on Linux, which
  means **no floating mode**. Under Wayland it only works through XWayland,
  so step 11's X11-window question decides whether VST3 GUIs work on
  Wayland at all.
- **Linux run loop.** VST3 plugins on Linux expect the host to provide an
  `IRunLoop` for their timers and file descriptors. It hooks into the same
  pump as step 04.
- **Scanning.** `.vst3` bundle folders in `~/.vst3`, `/usr/lib/vst3`,
  `/usr/local/lib/vst3`, and `moduleinfo.json` when the bundle has one (it
  avoids loading the plugin at all).
- **Saved form.** `PluginFormat::Vst3` with the class id as a hex string.
