# 03 — filter by format

A chip per plugin format that is installed (CLAP, VST3, AU), on the filter
row. None on means all. Each row's detail names its format.

Only CLAP is hosted today, so this shows one chip until plugin-hosting step
12 adds VST3; the chips come from the catalogue, not a fixed list, so VST3
and AU appear when they are scanned without touching this code.

**Done when** a catalogue with two formats offers two chips and each narrows
the list to its own format.
